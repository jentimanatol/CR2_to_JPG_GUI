# CR2 to JPG GUI

**Version 1.0**

A simple Windows desktop application for converting Canon `.CR2` RAW photos to high-quality `.JPG` images.

The application is designed for easy batch conversion with a graphical interface. It keeps the original RAW files untouched and can convert an entire folder of CR2 images at once.

## Features

- Convert Canon `.CR2` RAW files to `.JPG`

## How to Use

1. Download the latest Windows executable:

   `CR2-to-JPG-Converter.exe`

2. Double-click the EXE to open the application.

3. Click **Browse** and select the folder containing your `.CR2` photographs.

4. Optionally select a separate output folder.

   If no output folder is selected, the JPG files are saved beside the original CR2 files.

5. Select the JPEG quality.

   Recommended:

   ```text
   95
   ```

6. Click:

   ```text
   Convert CR2 to JPG
   ```

7. Watch the progress bar and conversion log.

8. When conversion is complete, click:

   ```text
   Open Output Folder
   ```

## JPEG Quality

The default JPEG quality is:

```text
95
```

This provides very high image quality while producing files significantly smaller than the original CR2 RAW photographs.

You can adjust the quality depending on your needs.

Typical values:

| Quality | Recommended Use |
|---|---|
| 100 | Maximum JPEG quality / larger file |
| 95 | High-quality photography |
| 90 | Good general-purpose quality |
| 80 | Smaller files / web use |

## RAW Processing

The application uses:

- Python
- Tkinter
- rawpy
- LibRaw
- Pillow
- NumPy

`rawpy` uses the LibRaw RAW decoding library to process Canon CR2 files.

The converter uses camera white balance when available and exports an 8-bit JPEG image.

### Important

RAW processors can render the same RAW photograph slightly differently.

The JPG produced by this application may therefore look somewhat different from JPG files generated by:

- Canon Digital Photo Professional
- Adobe Camera Raw
- Adobe Lightroom
- Darktable
- Capture One

This is normal because each RAW processor uses its own color and image-processing pipeline.

## Build the Windows EXE Locally

The project includes:

```text

```

Double-click it to automatically install the required build dependencies and create the Windows executable.

You can also build manually.

Install build dependencies:

```bash

```

Build with PyInstaller:


After a successful build, the EXE will be located at:


## Troubleshooting

### Windows says the application is from an unknown publisher

This can happen because the executable is not digitally code-signed.

Windows SmartScreen may display a warning for newly downloaded unsigned applications.

If you built the executable yourself from this repository, you can verify the source code before running it.

---

### No CR2 files are found

Make sure:

- The selected folder contains `.CR2` files
- You selected the correct source folder
- Enable **Include subfolders** if the RAW files are inside subdirectories

---

### JPG already exists

By default, existing JPG files can be skipped to protect previously converted photographs.

Enable overwrite if you intentionally want to recreate them.

---

### EXE build fails

Verify that Python is available:

```bash
py --version
```

Then install the build requirements:

```bash
py -m pip install -r requirements-build.txt
```

Run:

```bash
py -m PyInstaller --clean --noconfirm CR2_to_JPG.spec
```

## Safety

The converter is designed to preserve the original photography files.

It does not intentionally delete the source `.CR2` files.

For important photographs, keeping a backup of the original RAW files is always recommended.
